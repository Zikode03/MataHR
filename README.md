# MataHR

Matateni Technologies HR platform. The React/TypeScript frontend is in `frontend/`; the ABP backend is maintained in `Zikode03/MataHR-Backend`.

There is one frontend application, organised into `app`, `features`, `shared` and `styles`. Its implemented workflows use backend APIs. Unused prototype pages and demo stores have been removed.

Start the backend on `https://localhost:7043`, then run from this repository root:

```powershell
npm install
npm run dev
```

Open `http://localhost:5173`. See [frontend setup](frontend/README.md) and [module status](docs/module-status.md) for the implemented scope, limitations and unfinished requirements.
