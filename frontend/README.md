# MataHR frontend

Angular 20 standalone application. Use Node.js 22.12+ (Node 22 LTS recommended).

```sh
npm install
npm start
npm run build
```

Development URL: http://localhost:4200. Dashboard, employee search and attendance simulation are implemented as UI prototypes; other routes are explicit placeholders. No real HR data, authentication, role enforcement, payroll or attendance verification exists yet. Do not deploy for production. Brand palette approximated from the supplied Matateni website screenshot. The M mark is temporary, not the official logo.
